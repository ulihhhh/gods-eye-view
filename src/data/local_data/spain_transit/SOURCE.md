# Spain transit network pack

Generated by `scripts/build-spain-transit-network.mjs`. Regenerate with:

```bash
node scripts/build-spain-transit-network.mjs
```

when Renfe or FGC publish new timetables (Renfe's GTFS change monthly).

## `stations.json`

`networks.<network>.<stopId> = [name, lat, lon]` (`lat`/`lon` absent when the
source has no point). Networks:

| Network           | Keyed by                                        | Source                                                                                                  | Licence                                          |
| ----------------- | ----------------------------------------------- | ------------------------------------------------------------------------------------------------------- | ------------------------------------------------ |
| `renfe-cercanias` | GTFS `stop_id`, as Renfe's GTFS-Realtime reports | `https://ssl.renfe.com/ftransit/Fichero_CER_FOMENTO/fomento_transit.zip` → `stops.txt`                  | CC BY 4.0 — Renfe Operadora, data.renfe.com      |
| `renfe-ld`        | GTFS `stop_id`                                  | `https://ssl.renfe.com/gtransit/Fichero_AV_LD/google_transit.zip` → `stops.txt`                         | CC BY 4.0 — Renfe Operadora, data.renfe.com      |
| `fgc`             | Geotren station initials ("PC")                 | dadesobertes.fgc.cat `codigo-estaciones` (names) and `gtfs_stops` (points)                              | CC BY 4.0 — Ferrocarrils de la Generalitat de Catalunya |

## `lines.json`

`lines[] = {network, group, line, color, mode, paths}`; `paths` are flat
`[lon, lat, lon, lat, …]` arrays.

| Network           | Source                                                                                         | Notes                                                                                                   |
| ----------------- | ---------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| `renfe-cercanias` | `fomento_transit.zip` → `shapes.txt` (one direction per line; `_INV` dropped) and `routes.txt` | `group` is the Cercanías network ("núcleo") from the id prefix: 10 Madrid, 51 Rodalies de Catalunya, … |
| `fgc`             | dadesobertes.fgc.cat `gtfs_routes` (each line's MultiLineString and colour)                    | bus and shapeless routes dropped; lines sharing one geometry merged ("S9 · L8")                         |

Every path simplified with Douglas–Peucker at 10 m, coordinates rounded to
5 decimals. Where a Cercanías line has two colours in `routes.txt`, the most
common one is kept.

## `ign_rail.json`

Spain's mainline railway network (`paths[] = [lon, lat, lon, lat, …]`), the
Rail network layer's national context lines. Generated by
`scripts/build-spain-rail-ign.mjs` (slow: ~90 WFS pages; `--cache DIR` keeps
them for a rerun).

| Source                                                                                                             | Licence                                           |
| ------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------- |
| IGN "Redes de transporte de España", INSPIRE WFS `https://servicios.idee.es/wfs-inspire/transportes` (`tn-ra:*`) | CC BY 4.0 — © Instituto Geográfico Nacional — SCNE |

Transform: links of lines typed `train` only (metro, tram, funicular and cog
railway lines, and links on no line — sidings and yards — dropped); links
that meet end to end chained into longer paths (a junction ends a chain);
Douglas–Peucker at 50 m; coordinates rounded to 4 decimals (~11 m).

## Transform (stations)

Names trimmed with inner spaces collapsed; coordinates rounded to
5 decimals; keys sorted. Renfe data are cited as "Renfe Operadora"; no
endorsement by Renfe or FGC is implied.
