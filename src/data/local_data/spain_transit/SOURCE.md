# Spain transit network pack

Generated by `scripts/build-spain-transit-network.mjs`. Regenerate with:

```bash
node scripts/build-spain-transit-network.mjs
```

when Renfe or FGC publish new timetables (Renfe's GTFS change monthly).

## `stations.json`

`networks.<network>.<stopId> = [name, lat, lon]` (`lat`/`lon` absent when the
source has no point). Networks:

| Network           | Keyed by                                        | Source                                                                                                  | Licence                                          |
| ----------------- | ----------------------------------------------- | ------------------------------------------------------------------------------------------------------- | ------------------------------------------------ |
| `renfe-cercanias` | GTFS `stop_id`, as Renfe's GTFS-Realtime reports | `https://ssl.renfe.com/ftransit/Fichero_CER_FOMENTO/fomento_transit.zip` → `stops.txt`                  | CC BY 4.0 — Renfe Operadora, data.renfe.com      |
| `renfe-ld`        | GTFS `stop_id`                                  | `https://ssl.renfe.com/gtransit/Fichero_AV_LD/google_transit.zip` → `stops.txt`                         | CC BY 4.0 — Renfe Operadora, data.renfe.com      |
| `fgc`             | Geotren station initials ("PC")                 | dadesobertes.fgc.cat `codigo-estaciones` (names) and `gtfs_stops` (points)                              | CC BY 4.0 — Ferrocarrils de la Generalitat de Catalunya |

Transform: names trimmed with inner spaces collapsed; coordinates rounded to
5 decimals; keys sorted. Renfe data are cited as "Renfe Operadora"; no
endorsement by Renfe or FGC is implied.
